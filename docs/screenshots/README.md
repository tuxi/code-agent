# TUI Screenshots

Place real terminal captures of the TUI here, referenced from README.md:

- `tui.png` — light-theme TUI capture (default)
- `tui-dark.png` — dark-theme capture (used when the reader's OS is in dark mode)

How to capture (macOS): run `codeagent`, then press `Cmd+Shift+4` and drag
over the terminal window; save the file here as `tui.png`. Terminal.app and
WezTerm both render the TUI correctly.
